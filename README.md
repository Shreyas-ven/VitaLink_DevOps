# VITALINK
## Organ & Blood Donation Management System

VITALINK is a secure healthcare management platform designed to connect hospitals and simplify the coordination of organ donation, blood availability, transplantation requests, and emergency medical requirements.

The system enables verified hospitals to post available organs and blood units, request resources from other hospitals, manage incoming requests, and receive notifications regarding request status.

---

## 🚀 Project Overview

Organ and blood availability can be time-sensitive, especially during medical emergencies. Traditional communication between hospitals can cause delays in identifying available resources and coordinating requests.

VITALINK provides a centralized hospital-to-hospital platform where hospitals can:

- Register and access the system securely
- Manage available organs
- View organs available across hospitals
- Send and receive organ requests
- Manage blood availability
- Send and receive blood requests
- Accept or reject requests
- Track request status
- Receive notifications
- Coordinate emergency requirements

### Core Objective

> **Connecting Hospitals. Saving Lives.**

## 🫀 Organ Management

Hospitals can manage organ availability through the platform.

### Available Operations

- Post available organs
- View available organs
- View donor hospital information
- Request an available organ
- Track organ requests
- View incoming organ requests
- Accept organ requests
- Reject organ requests

### Organ Request Information

Each request contains:

- Patient Name
- Patient Age
- Blood Group
- Organ Required
- Urgency Level
- Reason for Transplant
- Requesting Hospital
- Donor Hospital
- Request Status
- Hospital Message

# 🩸 Blood Management

VITALINK also provides a dedicated blood management module.

### Blood Availability

Hospitals can post available blood units with:

- Blood Group
- Quantity
- Expiry Date
- Hospital
- Availability Status

Supported blood groups include:

- A+
- A-
- B+
- B-
- AB+
- AB-
- O+
- O-
